# ADR: Bot stack — Node.js + discord.js + TypeScript, no web UI

## Status

Accepted

## Context

Starting a new Discord bot for the "Developer Discord" server. First feature is a member onboarding questionnaire delivered entirely through Discord's native interaction components (modals, buttons, select menus). No separate web dashboard is planned at this stage.

## Decision

Use Node.js with the `discord.js` library, written in TypeScript. No CSS/UI framework is included since the project has no web-facing surface. Tests will use Vitest.

## Consequences

- Type-safe interaction payloads and autocomplete against the Discord API surface.
- No SCSS/CSS/frontend conventions apply to this project; `.claude/skills` installed are limited to `error-handling`, `git-conventions`, `typescript-conventions`, `testing-conventions`.
- If a web dashboard is added later, styling/UI stack and conventions will need to be decided and the corresponding skills installed at that time.
